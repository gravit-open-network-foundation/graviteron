# Contributing to Graviteron

Thank you for your interest in contributing to **Graviteron** — the fundamental unit of verifiable trust.

## How to Contribute

1. **Fork** the repository.
2. Create a feature branch (`git checkout -b feature/amazing-improvement`).
3. Make your changes.
4. Ensure all tests pass (`pytest`) and code formatting aligns with PEP 8 (run `ruff` and `black`).
5. Submit a **Pull Request** detailing your changes.

## Areas of Contribution

- **Mathematical models**: Enhancing components of the Trust Tensor or weights optimization.
- **Validators & Clients**: Developing quantum-resistant signature validations.
- **Integration**: Constructing SDKs for Rust, JavaScript, and other platforms.
- **Ecosystem**: Updating specification files, schemas, and research papers.

## Code of Conduct

We adhere to the [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md). Please read it to understand our community guidelines.
